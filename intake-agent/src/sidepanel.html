Perception

Perceive = read the page the way a screen reader does, not the way a scraper does. The agent asks Chrome for the page's computed accessibility tree — every node's role (button, textbox, dialog), its accessible name, its value and its state — then keeps the nodes a study builder could act on plus the nodes that explain them, and drops layout wrappers. Roles and names are the one layer every eSource platform agrees on, so nothing here is tied to a particular DOM.

Ledger

One row per plan item: which entry in the input file it came from, what was decided, where that decision came from, what read back, and how many attempts it took. Traceability as a by-product of the loop rather than a separate mechanism.
